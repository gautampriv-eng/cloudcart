Repository Structure:
- src/             : Spring Boot 3.3.5 / Java 17 REST API microservice with /api/products, /api/orders, /api/info, /health
- pom.xml          : Maven build file with dependency management and packaging configuration
- Jenkinsfile      : Multi-stage Declarative CI Pipeline (Checkout, Build, Test, Package, Archive, Docker Build)
- .github/         : GitHub Actions CI workflow (.github/workflows/ci.yml)
- ansible/         : Ansible Playbook, inventory, and cloudcart role (tasks, handlers, templates, defaults)
- Dockerfile       : Multi-stage container build (builder & eclipse-temurin runtime)
- k8s/             : Kubernetes manifests (ConfigMap, Deployment with 3 replicas & probes, NodePort Service)
- report/          : Overleaf LaTeX template, 17 authentic Ubuntu terminal screenshots, and compiled 23-page PDF report
